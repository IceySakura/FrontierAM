# 稀疏系统的指数传播

实现一个程序，在给定精度和资源预算下，尽快完成一个数值计算会话。会话固定实对称半正定稀疏矩阵L、时间t和误差要求，依次收到一个或16个向量对。对第j个向量对，返回完整向量

\[
y_j=e^{-tL}b_{0,j}+t\varphi_1(-tL)b_{1,j},\qquad
\varphi_1(z)=\sum_{k=0}^{\infty}\frac{z^k}{(k+1)!}.
\]

矩阵函数由同一幂级数定义，phi1(0)=1；L可以奇异。等价地，这是u'(s)=−Lu(s)+b1、u(0)=b0在s=t的状态。t=0时结果为b0。不要假设L可逆、每行和为0、非对角元非正或向量非负。

## 输入范围和会话

- 1≤n≤120000，非零数nnz≤1000000；输入为完整CSR矩阵而非只存上三角。
- L数学上实对称半正定；所有存储值均为有限binary64。实际收到的矩阵是计算对象，不要求重建生成器的理想矩阵。
- 0≤t≤10000，||L||∞≤1e8，t||L||∞≤1e5；这里矩阵无穷范数为最大绝对行和。
- 每个右端分量在[−1,1]。允许零矩阵、零向量和零特征值。
- one_shot会话只有1个请求；reuse会话有16个请求。同一会话的L、t和精度固定，只有b0、b1改变。
- 下一请求在上一请求完整输出后才揭露。你可以在会话内保存和复用任何合法状态；不能预先获取后续右端。每个会话和每次统计重复均从干净进程开始。

算法自由。可以使用预装数值库及其高层函数，也可以自行实现、组合或修改算法。资源限制内的时间空间取舍合法；所有与当前输入有关的准备工作、缓存及临时数据都纳入本次资源计量。

## 精度

会话指定以下一个精度档；程序不得自行改变：

| 档位 | rtol | atol |
|---|---:|---:|
| p4 | 1e−4 | 1e−7 |
| p7 | 1e−7 | 1e−10 |
| p10 | 1e−10 | 1e−13 |

对每个完整输出，裁判独立检查

`max(abs(y-y_ref)) <= atol + rtol*max(abs(y_ref))`。

这是全向量的混合绝对相对无穷范数，不是每个分量分别作相对误差。所有输出必须有限，所有请求和三次重复均须通过。独立参考未具备可靠精度时属于评测故障，不记为你的错误。

## 接口和计时

实现标准输入/输出进程接口，详细字节布局见[API.md](API.md)。准备好接收输入后，只输出`READY`加换行并刷新。此时尚未提供L、t或任何右端。初始化最多15秒。

控制器在交付矩阵第一个字节前开始计时；时间覆盖矩阵读取、转换、输入相关准备、全部请求和输出，终点取全部输出收齐与程序正常退出两者较晚的时刻。允许在READY之前导入通用库或完成与输入无关的初始化；不允许提前读取会话输入。普通离线构建另有预算，其费用不除以统计重复次数摊入主分；输入相关生成代码或即时编译仍计入会话时间。

输出只能包含READY行及各请求的原始向量字节。诊断写stderr。不得输出自报score、计时或正确性来替代裁判结果。

## 资源预算

| 项目 | 限制 |
|---|---|
| 执行资源 | 整个进程组共享1个逻辑CPU、4GiB内存，无GPU、网络或附加swap |
| one_shot | 数值会话墙钟15秒；整个进程CPU累计15秒，包含初始化 |
| reuse | 数值会话墙钟60秒；整个进程CPU累计60秒，包含初始化 |
| 状态 | 会话内可复用；跨会话和统计重复不复用 |
| 临时盘、日志 | 256MiB；stderr每会话最多4MiB |
| 进程与文件 | 含线程共32个PID；每进程128个文件描述符 |
| 构建 | 600墙钟秒、600CPU秒、4GiB；最终产物≤1GiB；构建时没有测试输入 |
| 开发 | 一次2小时墙钟，1CPU、4GiB；预算内公开开发测试不限次数 |

这些是本版本的约定预算；正式发布必须先完成隔离和参考标定。本地开发工具不证明宿主上已强制实现所有限制。

## 评分

同一会话独立运行三次，取完整数值会话时间的中位数，内存取三次最大值。任何必做会话、请求、格式、精度或资源检查失败，主分为0，同时给出开发覆盖率和失败反馈。不能只选成功子集。

完整合格时，令r_i=T_i/T_ref_i。先在同母算子的工作负载内平均，再依次按母算子、结构族、会话场景和精度档等权平均，得到R；主分为`100/(1+R)`。同一母算子的变体不会自动变成独立结构证据。控制例必须通过，但不参与时间均值。评分实现公开，见`tools/scoring.py`。

参考自身为50分；每项时间均减半为66.67分。内存仅设硬上限并单列报告，不为省内存额外加分。超过50意味着约定平均归一化时间下降，不表示每例都更快、每项内存都更低，或已经证明研究突破。

最终参考由维护者在相同环境中预先冻结，是可执行策略，不逐例事后选最快方法。参考代码和最终测试时延不向开发阶段开放。当前修订包尚无正式标定参考，本地工具返回原始指标，score为null；它不会拿旧计时冒充新协议成绩。

## 数据和可见材料

公开开发集、参考输出、数学验证逻辑与本地测试工具可自由查看。结构族包含空间扩散离散、几何图以及网络来源算子；测试也允许非零非负对角势，PSD条件不局限于纯图拉普拉斯。规模、刚性、精度和会话长度都会变化。最终分布需在正式评测开始前冻结并公开汇总；精确矩阵、向量、随机种子、清单和参考输出保留在评测侧。最终测试不得超出公开范围或新增未声明约束。

你可以查阅预装库的文档与源码；本任务是离线开放工具研究优化，不是限制使用已有算法的闭卷实现题。公开包不附特定论文、作者解法、基线调参记录或最终测试反馈。正式做题环境不提供联网检索、远程计算、宿主文件或私有裁判访问能力；当前本地开发工具自身不构成这种隔离。做题agent仅配备受限环境内的终端、文件读写和公开测试工具，不启用外部连接器或子agent。

开发阶段没有隐藏集查询。开发结束时只冻结一份提交的文件哈希，由独立评测运行；最终反馈在开发窗口关闭后才给出，不用于继续选候选。违规访问私有资源、修改控制器或伪造测量无效。

## 提交和自检

提交完整源码、依赖说明、可重复的构建入口及执行命令。不得在构建或运行时联网安装依赖。允许的环境见[ENVIRONMENT.md](ENVIRONMENT.md)；若最终Linux环境与开发宿主不同，以冻结发布环境为准。

`starter/solve.py`提供接口框架，不提供求解算法。先完成它，然后在公开目录运行：

```sh
python tools/run_local.py --manifest samples/manifest.json --command "python starter/solve.py" --repeats 3 --output dev_report.json
```

公开样例也包括解析小例，可先检查字节顺序、flush、奇异矩阵、t=0及16次请求生命周期。程序必须用收到的输入计算输出；私有文件名和实例标签不属于接口信息。

# 指数传播 v2 修订说明（优先于 INSTRUCTION.md 与 PILOT.md 中的对应条款）

接口（FAMEXP2）、精度判据、每会话资源上限、构建规则、`tools/run_local.py` 与 `tools/scoring.py` 均与原版相同。以下三点改变：

## 1. 参考时间：已发表人类方法的逐例最快值

原文“最终参考是一个可执行策略，不逐例事后选最快方法”作废。v2 的参考是一组事先冻结的人类参照实现（panel），全部来自已发表的方法和作者代码：对称 Lanczos/Krylov、自适应 Krylov 的 φ 函数组合、截断 Taylor 加缩放（两种实现）、谱区间上的 Chebyshev 展开。参数只在公开开发数据上按事先声明的规则选定，在任何 agent 提交之前冻结。

评测时，每个用例的参考时间 `T_ref_i` 取该用例上**三次全部合格的 panel 成员中，中位时间最短的那一个**。之后的层级平均与 `tools/scoring.py` 完全相同，主分仍为 `100/(1+R)`：参考自身为 50 分；平均归一化时间减半为 66.67 分。panel 源码与私有计时不提供给开发阶段。

## 2. 数据规模

正式测试的算子规模在 `n` 2 万至 12 万、`nnz` 不超过 100 万之间。来源包括标准稀疏矩阵集合中的有限元/扩散矩阵和真实网络图（转为组合拉普拉斯），以及合成的扩散、几何图、重尾网络、带符号关联矩阵和对数谱算子；`t·||L||∞` 从 1e-2 到 1e5 分层。母算子在公开集与测试集之间不重合。

每个用例的计时是从第一个请求发出到最后一个结果返回（reuse 为 16 个请求依次往返），进程启动不计入时间，但单会话墙钟与 CPU 上限不变（one_shot 15 秒，reuse 60 秒）。

## 3. 样例数据

- `samples/`：缩小规模的样例，6 个用例（5 个合成结构族各 1 例，加 1 个解析控制例）。

所有参考输出都经过两种独立方法交叉验证：扩展精度 Chebyshev 展开为主，双精度截断 Taylor 审计，两者差异不超过容差的 2%（审计方法不可靠的病态例改用稠密特征分解仲裁）。

运行示例：

```sh
python tools/run_local.py --manifest samples/manifest.json --command "./run.sh" --repeats 3 --output dev_report.json
```
