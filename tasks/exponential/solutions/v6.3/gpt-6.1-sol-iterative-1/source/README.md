# Sparse Exponential Propagation

This submission implements the FAMEXP2 streaming protocol in C++17.
It computes `exp(-t L) b0 + t phi1(-t L) b1` without assuming invertibility,
graph signs, or a zero row sum.

## Numerical Methods

- Low-stiffness sessions use adaptive Taylor evaluation directly on the received
  CSR arrays, with an infinity-norm remainder bound.
- Diagonal matrices and disconnected small blocks use direct spectral evaluation.
  The two-by-two path uses extended precision at the tightest accuracy level.
  Other small blocks use extended-precision eigenvectors, with binary128
  Rayleigh refinement at the tightest precision. Small full operators use a
  binary128 polynomial recurrence.
- The general path uses a combined Chebyshev expansion on a spectral interval
  bounded by absolute row sums and Collatz bounds for the absolute matrix.
  Scaled Bessel coefficients are generated by backward recurrence, and phi1
  coefficients by positive tail summation. Reinsch's endpoint form of Clenshaw
  evaluates both functions with one sparse product per polynomial degree.
  The truncation bound is checked against the actual output scale.
- AVX2 kernels use diagonal storage for regular sparsity patterns and
  SELL-C-4 with local row sorting for irregular patterns. CSR remains a fallback.
- Selected stiff sessions try eight complex shifted systems, using a
  preconditioned complex-symmetric CG iteration. Acceptance requires an
  extended-precision residual audit against the original stored matrix and a
  matrix-function approximation error bound. A short Lanczos probe handles
  low-dimensional spectra. Unsuccessful probes fall back to Chebyshev.

The shifted solver uses order-16 CRAM exponential coefficients and a fixed-pole
relative minimax phi1 approximation. Its scalar relative error was verified
below `5.85e-15`; the solver uses a conservative `1e-14` bound. All coefficients
are included as source constants.

Exact sign congruences are applied only after checking consistency. Constant
null modes are used only after checking the row sums and proving summation
exactness from the binary significand range. Error-free subtraction checks
protect constant-component decompositions in cancellation-sensitive requests.
Near-linear cancellation requests also have a binary128 residual check for
nullspace propagation, without requiring constant vectors or zero row sums.

Matrix data, spectral bounds, coefficients, and packed kernels are reused within
the sixteen-request session. No state is kept between processes.

Dependencies: the installed GNU C++ compiler, libc/libstdc++, Eigen headers, and
OpenBLAS on Linux amd64 with AVX2/FMA. GCC supplies binary128 scalar arithmetic.
No network access, downloads, Python runtime, or agent tools are used.

## Build And Run

Build with `bash build.sh`; run with `./run.sh` from this directory. The build is
entirely offline and all required source is included. The launcher forces
single-threaded numerical libraries and retains the inherited CPU affinity.

Only the FAMEXP2 protocol is written to stdout: `READY\n`, then raw little-endian
float64 response vectors. Requests are read sequentially, and the process exits
after its final response. Input-specific preparation is performed after READY.

## Checks

Public checks use `/workspace/task/tools/run_local.py` with the supplied
sample manifest, with three repetitions. Development checks also include dense
eigendecomposition comparisons, analytic spectral references, exact steady
states, null-mode cancellation, subnormal inputs, sanitizers, and full-size
sixteen-request streams with up to 120,000 rows and 994,009 nonzeros.
The test data and development harness are not runtime dependencies.
