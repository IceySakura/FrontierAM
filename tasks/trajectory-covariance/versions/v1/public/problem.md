# 题目名称

从一条采样轨迹估计长期协方差

# 问题描述

研究者运行一次马尔可夫链蒙特卡洛采样，得到按时间排列的向量 $x_1,\ldots,x_M$，用它们的平均值估计多个量。若在同样条件下独立重跑，某些分量的平均值可能波动较大，两个分量的平均值也可能一起偏高。你的程序每次只得到其中一次运行的轨迹。

# 算法目标

给定这条轨迹，返回 $d\times d$ 的长期协方差估计 $H$。目标量为 $\Sigma=\lim_{n\to\infty}n\,\mathrm{Cov}(\bar X_n)$，其中 $\bar X_n$ 是一次长度为 $n$ 的运行的平均向量。对足够长的轨迹，$H/M$ 估计均值向量的协方差，$\sqrt{H_{jj}/M}$ 估计第 $j$ 个均值的标准误。**交付的矩阵是 $H$。**

# 算法约束

同一程序处理六种情形。模拟轨迹有线性动态的四维观测和有限状态链的五维观测。真实数据部分对一个贝叶斯回归模型使用三种采样机制，每步给出六维观测。输入坐标可能经过固定于本条轨迹的可逆线性变换和平移。程序可反复读取本条轨迹、自选算法、拟合参数或使用现成数值库。估计必须来自本例输入与通用算法，禁止查表返回特定模型的参考答案、识别测试文件后套用答案、追加采样或跨调用传递数据。

离线 Linux ARM64，每次调用独享一个逻辑 CPU，单线程，2 GiB 内存，无交换空间，墙钟上限 30 秒。时间包括程序启动、读取输入、计算和写完输出。需要随机性时用固定环境变量 `SEED=1`。可用 Python 3、NumPy、SciPy、R 或 C/C++，其他依赖随源码提供并能离线构建。

# 交付要求

在 `/workspace/submission/` 提交源码、可执行的 `run.sh` 和说明依赖、来源及运行方法的 `README.md`。需要构建时提供无参数的 `build.sh`，在评测前用相同 CPU 和内存配额构建一次，限 300 秒。每例启动全新进程，入口为

```sh
./run.sh /absolute/input/input.npy /absolute/output/pred.npy
```

输入和输出都是单个 NumPy .npy 数组，C 顺序、小端 float64、无 pickle。输入形状为 $(M,d)$，行序为采样时间，列序为本例的分量顺序。输入中没有情形标签或其他轨迹。请按相同列序写出形状为 $(d,d)$ 的有限、对称、半正定矩阵，正常退出。零特征值合法。

# 评测指标

评测方持有正定的参考矩阵 $S$。模拟情形的 $S$ 可从生成机制求出，真实数据情形的 $S$ 用独立长链估计。每次有效输出的误差为

$$e=\left\|S^{-1/2}(H-S)S^{-1/2}\right\|_F.$$

越小越好。数值验收取 $s=\max(1,\|H\|_F)$，要求 $\|H-H^\mathsf T\|_F\le10^{-10}s$，且对称化后最小特征值至少为 $-10^{-10}s$。评分前对允许的微小非对称取平均，并把容差内的负特征值置零。超时、超内存、非零退出、缺失或非法输出的该例按提交零矩阵计误差 $\sqrt d$，保留在平均数内。整份构建失败得 0 分。

模拟三种情形各取 5,000、10,000、20,000、40,000、80,000 步，真实数据三种情形各取 2,500、5,000、10,000、20,000、40,000 步。每档先对 1,000 条轨迹分别算误差后取算术平均，再对全部 30 档等权平均，得总误差 $L$。模拟与真实数据各占 50%。每条母链的五个前缀分开调用。耗时只作限额与诊断。

基础参照和强参照在相同正式输入上的总误差分别为 $a>b>0$。当 $L\ge a$ 得 0 分；当 $b\le L<a$ 得 $5(a-L)/(a-b)$ 分；当 $0\le L<b$ 得 $10-5L/b$ 分。对每份提交只换算一次，满分 10 分。
