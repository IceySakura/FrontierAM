# 单轨迹练习

每个目录的 `input.npy` 都是一条独立生成的人工轨迹。行按时间排列，列为分量。你的程序只读取这一个文件，输出一个与列数相同的方阵。所有数组都使用小端 64 位浮点数和 C 行优先顺序。

| 目录 | 行数 × 列数 | 已知参考的来源 |
|---|---|---|
| 01 | 5,000 × 4 | 各时刻独立的高斯向量。长期协方差等于单步协方差。 |
| 02 | 2,500 × 6 | 每个向量都包含当前与前一时刻的高斯扰动。把零阶协方差与前后各一阶交叉协方差相加就得到参考矩阵。 |

在本机安装 Python 3 和 NumPy 后，将输出存为 `prediction.npy`，用以下命令计算该轨迹的相对矩阵误差。

```sh
python3 check.py 01/reference.npy prediction.npy
```

误差越小越好。自查时用 `01/reference.npy` 同时充当两个参数，预期为 0。用同维全零矩阵作为预测，目录 01 的误差应为 2，目录 02 的误差应为 √6。检验器遇到错误形状、错误数据类型、非有限数值或超出容差的非对称或非半正定矩阵时，以非零状态退出。
