# 给出题人：三维荧光反卷积接入时的改动（2026-11-17）

题目已接入 FrontierAM（x86-64 评测机），有两处需要你知道。

## 1. 数值镜像在 x86-64 上重建

维护包只带 ARM64 镜像，`runtime/task/environment/Dockerfile` 只有 `FROM <摘要>`。我们按 ARM64 镜像内的 Python、pip 与 Debian 包清单在 x86-64 上重建同版本环境（Python 3.11.15、NumPy 1.26.4、SciPy 1.12.0、PyTorch 2.2.2 CPU、scikit-learn 1.4.2、gcc 12、R 4.2.2 等）。如果有原始构建配方，请发给我们以便核对。

## 2. 每例时限 0.500 秒 → 1.250 秒

本机评测核为 AMD EPYC 7K62。在 0.5 秒下两条参照 96/96 全部超时：仅 `import scipy.signal` 就要约 0.45 秒。放宽时限测得参照单例最长 RL20 0.579 秒、SHB10 0.565 秒（你在 Apple M 上为 0.231 / 0.202 秒）。时限按 RL20 的速度比放大：0.5 × 0.579 / 0.231 ≈ 1.25 秒，参照余量与你的设定相同（约 2.2 倍）。题面同步改为 1.250 秒。

## 3. 锚点本机重测

正式评分只取原始平均 nMSE，不用 `calibration/anchors.json`（它绑定原镜像与文件哈希）。本机 1.25 秒下：RL20 0.219945（与你的记录一致）、SHB10 0.161141（你的记录 0.161172）。CPU0 检查改为“单个 CPU”（每个评测槽固定到自己的 CPU）。

## 4. 顶端接近饱和（11-18 实测，供你参考）

本机 v6.3 结果（参照 = 50 分，\(100 - 50E/W\)，\(W = 0.1611\)）：sol 单轮 94.4（nMSE 0.0182）、sol 迭代 93.5、opus 迭代 92.9、hy4 迭代 85.0。sol 的两份提交识别高斯点、有限长直高斯管和平滑高斯片三类基元，经前向模型做 Poisson + 高斯读出噪声的似然拟合，无法解释的区域保留数值重建。题面公开了“管状、点状、混合与贴边结构”，属于正当先验，但体模基本由这三类参数化基元构成，强模型可以接近满分。若希望顶端仍有区分度，建议加入更丰富的体模（非参数纹理、弯曲或分叉纤维、密集重叠结构）。

另：v6.3 迭代设置的 public 反馈只能用 12 个公开样例（包里没有同分布的留出集），模型本地也能算出同样成绩。建议补一个同分布、不给真值的留出 public 集。
