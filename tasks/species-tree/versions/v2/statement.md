# 题目名称

从短基因的估计树推断物种树（250 个物种）

# 问题描述

一个实例包含 249 个内群物种和 1 个外群物种。对每个物种，在 50 个不同的基因座各有一段 200 bp 的序列。各基因座有自己的谱系历史，短序列又会引入估计误差，所以即使来自同一批物种，各基因估计出的亲缘关系也可能相互矛盾。

程序收到一个 UTF-8 文本文件 `genes.tre`，每行是一个基因座的一棵 Newick 估计树，共 50 行。每棵都是覆盖 250 个叶子的无根二叉树，以分号结束。叶标签视为字符串：`0` 为外群，`1` 至 `249` 是当例的内群标识，独立于亲缘关系分配。冒号后的非负枝长以每个位点的预期替换数为单位，可以为零。内部右括号后、冒号前的数值若存在，是该边的近似贝叶斯支持度，取值在 [0,1]；缺省表示没有报告，不能假设每条边都有数值。输入没有 DNA 序列、真实基因树或生成数据的物种树。

数据由多物种溯祖模型模拟：先生成物种树，再在其上模拟各基因座的真实谱系，沿谱系模拟序列，最后从序列估计每个基因座的树。

# 算法目标

对给定的 50 棵基因树推断一棵无根二叉物种树，使其尽可能恢复真实物种树的内部边。可使用或忽略枝长和支持度，自选推断方法。同一个程序处理全部实例。

# 算法约束

运行环境为离线 Linux，提供 POSIX shell、C/C++ 编译器和 Python 3。每例限 1 个逻辑 CPU、单线程、4 GiB 内存、无交换空间、180 秒墙钟。开发时可以查阅和使用公开方法，运行时所需的其他软件须随源码提交并能离线构建。求解只能使用本例输入和与实例无关的代码或参数；禁止按输入指纹查答案、跨例缓存或通信。每例独立启动一次；用到随机性时以环境变量 `SEED=1` 为固定起点。

# 交付要求

在 `/workspace/submission/` 提交源码、可执行的 `run.sh` 和说明依赖、来源及运行方法的 `README.md`。若需要构建，附无参数的可执行 `build.sh`；在同一 CPU 和内存配额下离线构建一次，时限 300 秒，构建时无评测输入。每例从提交目录启动：

```sh

```

在第二个路径写入恰好一棵以分号结束的 Newick 树并正常退出；输出的每个叶标签须与输入完全一致且恰好出现一次。最外层可从一个三度内部结点写起，也可在一条边上设临时二度根；消去该根后每个内部结点都须为三度。输出枝长和内部标签可省略。文件路径只作输入输出用途，日志写标准错误。180 秒从启动进程前算到输出文件关闭且程序退出，包括读取、推断及写出。

# 评测指标

删去一条内部边会把物种分成两组，称为一个分裂；两侧对调仍是同一个分裂。每棵 250 叶无根二叉树有 247 个这样的分裂。若提交和真树共有 $k$ 个分裂，本例归一化 Robinson–Foulds 误差为 $e=(247-k)/247$。只算拓扑：改写子树顺序、重定书写根或改变输出枝长不影响误差。提交与真树拓扑一致时 $e=0$。

正式集含 200 棵独立生成的物种树，每棵对应一个输入，每例运行一次。超时、超内存、异常退出、缺失输出或非法树的该例取 $e=1$。整批原始指标 $E$ 是全部 200 个误差的算术平均，越低越好。构建或整份入口失败得 0 分；评测平台故障须恢复后再出总分。另报失败数和耗时，耗时不参与分数或破同分。

基础参照、强参照在相同隐藏集与预算下实测的平均误差分别记为 $U,W$，满足 $U>W>0$。**平均误差 $U$ 得 0 分，$W$ 得 5 分，零误差得 10 分。** 先求整批 $E$ 再换算：

| 整批误差 | 项目分（满分 10） |
|---|---:|
| $E\ge U$ | $0$ |
| $W\le E<U$ | $5(U-E)/(U-W)$ |
| $0\le E<W$ | $10-5E/W$ |
