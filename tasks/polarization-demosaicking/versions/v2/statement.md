# 题目名称

从一张偏振马赛克重建四幅强度图

# 问题描述

相机在每个像素上只测量一个偏振方向的光强。给定一次曝光得到的单通道图像 `raw`，请估计同一画面在 0°、45°、90°、135° 下的四幅完整图像。滤片从图像左上角开始，按下表每两行、两列重复排列。行列从 0 开始。

| | 偶数列 | 奇数列 |
|---|---:|---:|
| 偶数行 | 90° | 45° |
| 奇数行 | 135° | 0° |

正式输入是形状为 `(1024, 1024)` 的 NumPy `uint8` 数组，读数在 0 至 255 之间。四幅目标图与输入坐标对齐。例如在偶数行、偶数列，输入给出了该位置的 90° 强度，其余三个方向需要估计。

# 算法目标

用同一个程序处理所有场景，使四幅重建图在**完整画面**上的强度误差尽可能小。一个像素的四个方向可以有不同亮度。程序可以使用整幅输入，自行决定怎样利用相邻像素以及不同方向的观测。

# 算法约束

每个场景在独立进程中离线运行，限 1 个逻辑 CPU、单线程、8 GiB 内存、无交换空间。每景墙钟时间上限为 **1.000 秒**，独立计时。计时从启动该景运行进程前开始，到完整写出结果且进程正常退出为止，包括 Python 启动、模块导入、输入读取、计算及输出写入。容器准备、一次性构建、评测端验分另计。平台提供 Linux ARM64、Python 3.11、NumPy 1.26.4 和 SciPy 1.12.0。

开发时可查阅和复用公开方法。运行时只能使用本景马赛克和通用于各景的源码、参数。禁止使用正式场景的完整参考图或其衍生数据进行训练、调参、识别场景查表或硬编码答案。每景使用干净的工作目录，禁止跨景保存状态。若使用随机算法，统一以环境变量 `SEED=1` 为起点。

# 评测指标

每景分别对四个方向计算全图均方根误差（RMSE）。若某方向的输出、参考图分别为 $P$、$R$，则该方向的误差为 $\sqrt{\sum_{i,j}(P_{ij}-R_{ij})^2/(HW)}$。图像四边、四角和已观测的像素都计入。每景先对四个方向的 RMSE 取算术平均，再对固定的 32 个场景等权平均，得到整批误差 $E$。每景评一次，$E$ 越低越好，整批只换算一次分数。

0 分对应经典方法的表现，5 分对应现有较先进方法的表现，10 分对应零误差的理论最优。两条参照在固定测试集上的整批误差分别记为 $B$、$H_5$，满足 $B>H_5>0$。项目分满分 10，按下表计算。

| 整批误差 | 项目分 |
|---|---:|
| $E\ge B$ | $0$ |
| $H_5\le E<B$ | $5(B-E)/(B-H_5)$ |
| $0\le E<H_5$ | $10-5E/H_5$ |

32 景均须成功。构建失败或任一景出现提交导致的超时、超内存、异常退出、缺失或非法输出，整份计 0 分。由提交导致的失败不重跑。平台故障修复后按原条件恢复。耗时和峰值内存另行记录，同分并列。
