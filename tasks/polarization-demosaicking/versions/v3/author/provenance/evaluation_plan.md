# vNext 评测方案（维护侧草案）

本文件是维护侧协议，不随公开题面发布。现有 v1.2 题包、评分器和历史结果保持只读。

## 数据和转换

- 正式场景：冻结 Qiu32 + Wen100，共 132 景；Wen5 为公开开发集，不计正式分。
- Wen 切分：固定 hash 规则，开发场景 `43,55,72,91,99`，其余 100 景隐藏。
- Wen 转换版本：`wen-gray-polar-v0`。对每张 RGB 参考按 `floor((R+2G+B)/4+0.5)` 转为 `uint8`，中心裁剪 `top=32,left=216,height=1024,width=1024`，参考顺序 `[0,45,90,135]`，相位为 `[[90,45],[135,0]]`。
- 原始数据、隐藏参考和转换后的图像只留在维护侧私有目录；数据权利人的再分发/公开部署许可仍是发布门槛。

## 误差、锚点和失败

对每个正式场景先取四通道 RMSE 的算术平均 (e_s)，再计算

\[
E=\frac{1}{132}\sum_s e_s.
\]

当前内部校准（待正式 scorer、独立审计和数据权利门控签收）为：

- `B=2.10798080792808`；
- `H5=1.5006853943125558`；
- 完美输出锚点为 0。

这两个锚点都是 Qiu32 与 Wen100 的同一全局均值；Qiu/Wen 分组均值只作诊断，不分别映射分数。任一正式场景发生提交导致的失败，整份分数为 0。

## 1 秒校准收据

使用 v1.2 worker 合约的独占 CPU 0、8 GiB、swap=0、1.000 秒/景：

- Wen5：双线性 5/5，镜像参照 5/5；
- Wen100：双线性 100/100，镜像参照完整重跑 100/100；
- 镜像参照首次批次场景 60 曾出现一次 1.001216625 秒瞬时超时；三次单景重跑及完整重跑通过，重跑最大墙钟 0.942451167 秒。

逐景 CSV、首跑失败记录和锚点重算输出见 `vnext/calibration/`。

## 发布门控

只有以下项目都通过，才创建新的公开包和维护包：

1. 数据权利人的再分发、服务器运行和开发集公开范围得到明确许可；
2. 转换和切分在干净环境逐文件复现；
3. vNext scorer/runner 在端点、跨数据集等权、失败、超时和非法输出用例上通过独立验分；
4. Harbor 开发试跑和隐藏正式验收通过；
5. 内容扫描确认公开包没有隐藏参考、锚点数值、内部场景清单或性能筛选解释；
6. v1.2 两个 tar.gz 的 SHA-256 和运行时验证结果保持不变。
