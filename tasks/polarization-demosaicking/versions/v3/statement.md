# 题目名称

从一张偏振马赛克重建四幅强度图（vNext 草案）

## 问题描述

相机在每个像素上只测量一个偏振方向的光强。给定一次曝光得到的单通道图像 `raw`，请估计同一画面在 0°、45°、90°、135° 下的四幅完整图像。滤片按下表每两行、两列重复排列，行列从 0 开始。

| | 偶数列 | 奇数列 |
|---|---:|---:|
| 偶数行 | 90° | 45° |
| 奇数行 | 135° | 0° |

输入是形状为 `(1024, 1024)` 的 NumPy `uint8` 数组，读数在 0 至 255 之间。四幅目标图与输入坐标对齐；输入只在对应方向的位置给出观测，其余方向需要估计。

## 算法目标

用同一个程序处理所有场景，使四幅重建图在完整画面上的强度误差尽可能小。程序可以使用整幅输入，自行决定如何利用相邻像素和不同方向的观测。

## 运行约束

每个场景在独立进程中离线运行，限 1 个逻辑 CPU、单线程、8 GiB 内存、无交换空间。每景墙钟时间上限为 **1.000 秒**，从启动该景运行进程前开始，直到完整写出结果且进程正常退出为止；包括 Python 启动、模块导入、输入读取、计算和输出写入。容器准备、一次性构建和评测端验分另计。运行环境为 Linux x86-64、Python 3.11、NumPy 1.26.4 和 SciPy 1.12.0。

开发时可查阅和复用公开方法。运行时只能使用本景马赛克和通用于各景的源码、参数；不得读取正式场景的参考图或其衍生数据，不得识别场景查表或硬编码答案。每景使用干净工作目录，禁止跨景保存状态。随机算法统一以 `SEED=1` 为起点。

## 评测与计分

评测包含固定的 **132 个正式场景**和单独的公开开发接口。公开开发结果只用于调试，不计入正式分数；正式场景清单和参考图由评测方保管。

每景分别计算四个方向的全图 RMSE，先取四个方向 RMSE 的算术平均得到该景误差 (e_s)，再对 132 个正式场景等权求平均得到 (E)。

0 分对应经典方法的表现，5 分对应现有较先进方法的表现，10 分对应零误差的理论最优。两条参照在同一批正式场景上的整批误差记为 (B) 和 (H_5)，满足 (B>H_5>0)。项目分按一次全局映射计算：

| 整批误差 | 项目分 |
|---|---:|
| (Ege B) | 0 |
| (H_5le E<B) | (5(B-E)/(B-H_5)) |
| (0le E<H_5) | (10-5E/H_5) |

正式场景任一景因提交导致超时、超内存、异常退出、缺失或非法输出，整份项目计 0 分。平台故障修复后按原条件恢复。耗时和峰值内存另行记录，同分并列。
