# 理论部分的评分原则与两次试跑的重评（2026-11-25）

## 1. 评分原则（用户 11-25 确定）

1. **理论应当经过形式化验证。** 只有机器检查通过的结论计分：Lean 4 加固定版本的 Mathlib，无 `sorry`，公理只用 `propext`、`Classical.choice`、`Quot.sound`，并且形式化陈述经评审认定忠实于自然语言陈述（不能证明一个更弱或无关的命题再声称是定理）。未经形式化验证的结论照常列出，但不计分。
2. **与人类强 SOTA 理论结果逐条对比。** 每条结论找出一个或多个最相关的人类强结果（给出处与准确陈述），归入三类之一：
   - **S：严格强于**某个人类 SOTA 结果（假设相同或更弱而结论更强，例如速率指数更好、常数更好、去掉关键假设；或在严格更大的类上得到同样的结论），即突破人类 SOTA；
   - **W：严格弱于**某个人类结果（被已知结果蕴含，或只是在特例上复现）；
   - **I：实质上不可比。** 此时依据人类论文本身表达的观点判断价值：作者明确写出的空白、开放问题或关心的量（例如速率、正则性、可计算性）是否因此得到推进。

## 2. 映射到 0–100（用户 11-26 确认）

沿用全库“参照 = 50”的约定，以人类 SOTA 结果为参照：

| 情形 | 单条结论得分 |
| --- | --- |
| 未经形式化验证，或形式化陈述不忠实 | 0（只记录） |
| W：严格弱于人类已知结果 | 0–50，按差距（例如速率差多少、是否只是特例） |
| 等同于题目所属问题上的人类强 SOTA（独立复现到同等强度） | 50 |
| 复现经典特例（对上的人类结果是更早、更窄、已被更一般结果覆盖的经典结论） | 50 以下，按与强 SOTA 的差距定分（用户 11-26 确定） |
| I：不可比 | 按人类论文的观点定价：推进了作者明确提出的问题则高于 50，否则低于 50 |
| S：严格强于人类 SOTA | 50–100，按改进幅度（指数改进、去掉关键假设接近 100） |

理论部分的总分取**形式化验证通过的结论中的最高分**（一个真正的突破就是我们要找的；用户 11-26 确认），完整的逐条表格随分数一起报告。没有通过的结论时理论分为 0。题面相应写明：理论结论要以 Lean 形式化并给出与人类结果的对比分类；环境提供离线的 Lean 4 与 Mathlib（v3.2 起，见第 4 节）。
