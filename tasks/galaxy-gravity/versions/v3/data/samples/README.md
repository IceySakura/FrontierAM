# 星系快照引力题 · 样例

本目录可单独使用。生成器需要 Python 3 和 NumPy，输出检查器仅使用 Python 标准库。输入和输出都是无文件头的小端 IEEE 754 binary64，按行连续存储。输入每行 32 字节，依次为质量和三维坐标；输出每行 24 字节，依次为同一粒子的三个加速度分量。行序就是粒子编号。所有样本取引力常数 1、软化长度 0.01。

## 检查自己的程序

`smoke.in` 包含 32 个粒子。`smoke.ref` 为对应的 32 个参考加速度向量，按输入的双精度数值用 60 位十进制精度逐项求和后舍入为 binary64。从本目录运行，将第一条命令中的程序路径换成你的可执行文件。

```sh
./solve smoke.in my-output.bin
python3 check_output.py my-output.bin
```

检查器验证文件长度、数值有限性，并打印逐粒子加速度向量相对误差的均方根（无量纲小数）。可以执行 `python3 check_output.py smoke.ref` 检查环境，预期打印 32 个向量、误差 0。这个小样本用于开发接口自检，正式成绩依题面规定的规模、资源和数据计算。

## 生成自己的开发快照

命令参数依次为模型、粒子数、非负整数种子、输出路径。例如下面的命令生成一张正式规模的输入文件。

```sh
python3 generate.py jaffe 131072 123456 dev.in
```

| 模型名 | 分布 |
|---|---|
| `smooth-hernquist` | 尺度半径 1 的 Hernquist 球，半径 100 处接平滑指数尾。 |
| `jaffe` | 尺度半径 1 的 Jaffe 球，半径 100 处接平滑指数尾。 |
| `einasto` | 指数 3.5、半质量半径 1 的单个 Einasto 球。 |
| `disc` | 三维标准高斯沿随机法向压缩到原厚度的十分之一。 |
| `group` | 四个等质量 Einasto 团，模型参数同单个 Einasto 球；粒子数须是 4 的倍数。 |

每张快照总质量为 1，所有粒子质量相等。单球和薄盘的中心均匀取自半径 4 的球体；四团模型独立生成四个中心，每团占四分之一的粒子，最后打乱粒子行序。使用相同版本的 NumPy、模型、粒子数和种子可以重生成同一输入。使用 `disc 32 4242` 可以重生成随包输入（制作时使用 NumPy 2.3.5）。生成器不需要外部数据。

## 正式规模的样例快照

`cases/` 下有 1 张正式规模（131,072 个粒子）的样例快照（`smooth-hernquist` 模型），种子与正式评测不同。`case-01.in` 为输入，`case-01.ref` 为按同一直接求和程序算出的参考加速度，`manifest.json` 列出它的模型和 SHA-256。其余各类模型的快照可用生成器自行生成。检查自己的输出：

```sh
./solve cases/case-01.in out.bin
python3 check_output.py out.bin --reference cases/case-01.ref
```
