# 题目名称

星系快照中的引力加速度

# 问题描述

一张快照记录某一时刻一个孤立星系中所有粒子的质量和三维位置。请计算每个粒子在这一时刻由其余粒子产生的引力加速度。设粒子 $i$ 的质量为 $m_i$、位置为 $\boldsymbol x_i$，则它的加速度为

$$
\boldsymbol a_i
=G\sum_{j\ne i}m_j\,
\frac{\boldsymbol x_j-\boldsymbol x_i}
{\bigl(\|\boldsymbol x_j-\boldsymbol x_i\|_2^2+\epsilon^2\bigr)^{3/2}}.
$$

所有快照使用相同的引力常数 $G=1$ 和软化长度 $\epsilon=0.01$。粒子间的位移直接取三维坐标之差。软化长度规定近距离粒子之间的引力大小，在计算近处和远处粒子的贡献时均应使用上述物理模型。

# 算法目标

交付同一个可重复运行的 CPU 程序，在每次调用的时限内返回**全部粒子**的加速度，使预测向量的整体相对误差尽可能小。正式快照每张含 131,072 个等质量粒子，总质量为 1。五类场景分别为 Hernquist 球、Jaffe 球、单个 Einasto 球、扁平星系盘和四个星团组成的群组。程序获得完整快照，可以根据粒子的实际空间分布选择计算方式。

# 算法约束

评测环境为 Linux ARM64。每次运行使用单进程、单个 CPU 线程，峰值内存上限为 2 GiB。正式标定时固定处理器机型与软件环境。允许自行选择算法和精度参数。若采用树算法，张角由提交程序自行设定，评测器不传入张角。可使用环境中已有或随源码提交的离线依赖。每次只能根据本次输入和随提交固定的程序数据求解，禁止跨调用保存、读取或交换与评测快照有关的结果。

**每张快照的每次调用最多使用 5.000 个进程 CPU 秒。** 按进程从启动到退出累计的用户态与内核态 CPU 时间计量，包含启动、读入、实例预处理、计算和写出。每次另设 30 秒墙钟上限，用于终止挂起的进程。每次评测均从新进程启动，三次调用的时间分别检查。评测器将环境变量 `GALAXY_RUN_SEED` 依次设为 `0`、`1`、`2`，随机算法可用它初始化本次运行。

# 交付要求

在 `/workspace/submission/` 提交可在评测环境中构建运行的源代码及必要依赖，在提交根目录提供可执行入口 `./solve`。需要构建时，提供可执行的 `./build.sh`，在提交根目录调用后应生成 `./solve`。整批评测前离线构建一次，限单核 120 个 CPU 秒、2 GiB 内存和 300 秒墙钟，构建时不能读取正式快照。评测器按 `./solve INPUT OUTPUT` 调用程序，两个参数分别为输入文件路径和本次要创建的输出文件路径。成功时写完并关闭输出文件，以状态码 0 退出。

| 文件 | 二进制格式 |
|---|---|
| `INPUT` | 无文件头，按行连续存储小端 IEEE 754 binary64。每行依次为 `m, x, y, z`，每行 32 字节，$N=$ 文件字节数除以 32。行序即粒子顺序。 |
| `OUTPUT` | 无文件头，同样以小端 binary64 存储，恰好 $24N$ 字节。按输入行序为每个粒子写出三个有限数 `ax, ay, az`，依次为原坐标系下三个方向的加速度分量。 |

# 评测指标

正式评测有 5 类快照，每类 4 张，每张用不同的新进程运行 3 次，共 60 次调用。**任一次因提交突破 CPU、墙钟或内存上限，违反执行约束，异常退出，或未写出规定长度的有限向量而失败，整份提交记 0 分，不进入有效精度排名。** 提交无法构建或启动同样计 0 分。经确认属于评测平台的故障由评测方重跑，不计为提交失败。全部调用有效后，按下述规则比较精度。

对一次调用，令 $\widehat{\boldsymbol a}_i$ 为提交的向量，$\boldsymbol a_i^{\rm ref}$ 为评测方对同一快照逐项累加全部其他粒子贡献得到的参考向量。正式计分快照中的每个参考向量均有非零模长。先按粒子计算向量相对误差，再在一张快照内取均方根。

$$
e = \sqrt{\frac{1}{N}\sum_{i=1}^{N}
\left(\frac{\|\widehat{\boldsymbol a}_i-\boldsymbol a_i^{\rm ref}\|_2}{\|\boldsymbol a_i^{\rm ref}\|_2}\right)^2}.
$$

每张快照取三次运行的 $e$ 的算术平均，每类取其四张快照的算术平均，最后将五类的结果等权平均，得到原始误差 $E$。$E$ 越低越好。方向偏差和大小偏差都会增加误差。只要 60 次全部在限时内有效，运行更快不会额外加分。

**0 分对应经典简单方法的基准水平，5 分对应现有较先进方法的基准水平。** 两份参照程序按相同资源和汇总规则标定原始误差 $E_0>E_5>0$，分别作为 0 分与 5 分的评分锚点。全部预测与参考值一致时 $E=0$，对应 10 分。有效提交的分数按原始误差分段线性插值。

$$
S(E)=
\begin{cases}
0,& E\ge E_0,\\
5\,(E_0-E)/(E_0-E_5),& E_5\le E<E_0,\\
10-5E/E_5,& 0\le E<E_5.
\end{cases}
$$
