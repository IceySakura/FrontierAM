# v3 困难扩展（草稿）

本版在原有反馈集与私有集各 15 条的基础上，各增加 15 条困难序列，合计 **30 条反馈＋30 条私有**。原始 v1/v2 数据与成绩保留，本版必须重新封存和标定后才能开放评测。

交接、导入、模型可见文件白名单和宿主样例服务的使用方式见 [使用指南（仅维护者）](USAGE_GUIDE.zh.md)。模型只接收独立六文件小包，不接收维护端总包、仓库或这份交接指南。

资源与原始指标不变：每例 `d=16384, T=50`，单线程、完整序列最多 30 秒、求解进程峰值 RSS 最多 256 MiB，比较平均归一化平方 H-能量误差。新增数据包含高维随机创新、全秩系数变化与阶段转换，重点检查历史解子空间的泛化能力。

- [题面](statement.md) 是给求解器的契约，不披露构造因子。
- [samples/](samples/README.md) 只提供协议工具和小型演示。完整规模样例取自反馈池，通过宿主 HVP 服务提供；生成代码、教师因子和参考解不进入开发工作区。
- [curator/](curator/README.md) 仅供维护者生成、验证和封存数据，不能打入模型可见样例包。
- [grader/evaluate.py](grader/evaluate.py) 用于本地检查和目标机重测，能读取原始与新增教师格式。未激活的草稿结果不产生正式分数。
- `references/r1` 保留原 L-BFGS-PCG。新增的 `references/candidates/galerkin_cg` 是用于检验已知历史投影捷径的候选参照，不自动替换已公布锚点。

扩展的数据、固定私有种子和逐例答案通过独立 ZIP 交接。GitHub 只含题面、通用维护脚本和汇总验证记录。能否由某种新算法进一步识别或利用结构，不能由有限次测试排除；本版以明确的攻击基线与实验结果说明改善范围。

维护者收到扩展包并解压后，在包含本次变更的仓库根目录运行：

```sh
python scripts/seal/prepare_ihvp_hard_v3.py \
  --addition-root /path/to/ihvp-hard-v3-addition/data \
  --legacy-bundle /path/to/ihvp-sequence-v1
```

若原数据已按旧流程准备，则以 `--legacy-data-root var/raw/ihvp-sequence-v1/data` 代替 `--legacy-bundle`。默认输出为忽略路径 `var/raw/ihvp-sequence-v3/data/`，含 30 条反馈、30 条私有与两个从新增反馈中选取的宿主样例；校验哈希并保留原数据字节，不重新生成任何序列。完整验证结果见 [HARD_V3.md](../../analysis/HARD_V3.md)。

发布前还需确认反馈总时长：30 条各用满 30 秒已达 900 秒，不含加载和验分，不能直接宣称满足现行每次反馈 15 分钟的总限制。维护者须明确分批反馈或调整总时限，再校准和开放；本草稿不静默改变协议。
