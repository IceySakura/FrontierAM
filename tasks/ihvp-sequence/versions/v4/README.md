# v4 全新时序系统与独立留出集（草稿）

采用 **15 条全新 public＋30 条全新 private**；旧 v1–v3 数据和结果保留，只作回放，不进入本版计分。资源、在线 HVP 契约和 CG=0 / L-BFGS-PCG=50 / 零误差=100 的映射不变。目标 Linux amd64 的重新标定和隔离验收完成前，不激活正式分数。

本版针对 v3 迭代程序学到的固定蝶形配对：每个旋转层独立随机配对，随机深度，并与复合正交变换混合。高维创新和有用的时序相关性保留。public/private 来自同一分层混合分布、使用独立拓扑与参数；不故意把 public 做易、private 换成另一类题。

这能消除已知固定配对指纹，不能证明所有合法结构学习方法都失效。通过 HVP 学到有用信息仍是允许的算法行为。当前没有证据表明此前模型读取了 private；本版解决的是跨集合共有结构被 public 反馈识别，以及 private 被反复反馈造成调参的问题。

- 模型材料：[题面](statement.md) 和独立六文件样例小包。
- 维护者流程：[使用指南](USAGE_GUIDE.zh.md)，禁止交给被测模型。
- 构造与限制：[curator/README.md](curator/README.md)，仅维护者可读。
- 实测与边界：[HARD_V4.md](../../analysis/HARD_V4.md)。

维护者先在 public 上验证固定程序并冻结源代码、参数、设计和证据，再一次性生成 private。开发反馈仅整池汇总，不提供逐例、构造族或 private 结果。正式 private 评测之后不再针对同一 holdout 继续开发并把它称为隐藏测试；后续改动须开新版本、新 holdout。
