# v4 维护端构造（禁止交给模型）

固定 d=16384、T=50。构造 F_t=B_t sqrt(D_t) Q_t^T，H_t=F_t^T F_t，b_t=F_t^T y_t，x*_t=F_t^{-1}y_t。因此参考能量为 ||y_t||²，而 H 满秩正定；B 是特征值在 [0.8,1.2] 的全秩 2×2 块，D 的三档谱尺度为 1e5/1e6/1e7。

Q_base 使用每层独立均匀随机完美配对的 Givens 旋转，不再使用固定 i xor 2^k 配对。三种预先声明的混合配置：10–16 层随机路由；4–7 层随机路由加 2 层带符号/置换 DCT；3–6 层随机路由加 3 层 DCT。各例深度、角度、配对和置换独立。输出另有随机符号。Q_t 还包含两层在谱局部变化的时间旋转，保留连续求解的价值。

五种谱/时序场景 × 三个尺度构成 public 15 例；private 为相同设计的两个独立重复，共 30 例。每个场景在三个尺度上各包含一种变换配置，配置与尺度的配对在每个 split/重复中独立随机打乱。因此两池边际相同，无固定“场景→配置”映射。它是分层抽样，不能宣称 45 例严格同分布独立逐例抽样。

y_t 为全维 AR 随机创新（含均值回归或阶段重置）；不由 6 维平滑控制量生成。阶段突变位置在预定范围随机抽取，不再固定第 21/36 步。此轨迹是外生合成路径，不是求解误差会改变未来输入的闭环优化轨迹。

严格谱界来自 exp(-amp)≤D≤kappa exp(amp)、0.8≤eig(B)≤1.2 和 Q 正交，故 mu=0.64 exp(-amp)、L=1.44 kappa exp(amp)。模型稳定地用 F 计算能量，独立审计使用行向量实现，tiny 测试另外显式构造稠密 Q/F 并分解求解。

先生成 public，再做独立数学审计、冻结 v3 迭代程序的攻击回归和固定参照实测。不能按算法结果删除、重抽或挑选用例。private 生成需 FROZEN 收据绑定设计、模型、生成器、完整 public 证据和冻结方法。private 只做数学正确性/字节完整性检查；不根据 private 算法表现修改设计。

低秩 B 更新、共同对角化、DCT 识别或其他结构学习都不是题面承诺，也不由本设计证明不可能。随机路由只移除已知固定配对，不提供密码学隐藏保证或算法下界。
