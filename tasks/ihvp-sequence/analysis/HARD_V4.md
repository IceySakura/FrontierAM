# IHVP v4：全新留出集与已知结构回归（维护者材料）

本版依据出题人确认，采用 **15 条全新 public＋30 条全新 private**。旧数据与旧成绩保留，旧数据在 v4 正式评分中的权重为零。v4 是新版本草稿，v3 当前的正式状态与所有历史格子不改动。

此前证据说明模型从 public 的合法 HVP 查询识别了跨集合共有的固定配对，不能据此认定它读取了 private。改变比例不能单独解决共有结构的指纹；禁止 private 在开发期间反馈，解决的是对留出结果反复适配。

## 数据与流程

每个旋转层改为独立随机完美配对，深度随例变化，另混合复合正交变换；不再存在所有实例共享的固定位配对。全维创新、谱变化和有用的时序相关性保留。三类配置在每个场景的三个尺度上独立打乱，两个池采用相同分层抽样规则；private 是两个独立重复，不是另一种隐藏分布。阶段切换位置也在预先固定的区间随机化。

先封存 public 的 15 个种子计划，再完整测试预先固定的程序；所有用例保留，不根据算法结果挑选或重抽。public 资格、设计、源代码和方法绑定收据冻结后才一次性生成 private。private 只做数学审计，没有运行算法筛选或调参。详细种子/逐例教师与验证文件只在维护端 ZIP 中。

## 已知固定配对的回归

对未修改的 v3 `LearnedBasis.fit` 在每例首步及阶段切换点做额外探测，共 **21 次，接受 0 次**。该诊断给予每次 30 秒上限，用 Python 返回追踪只观察拒绝残差、不改变程序控制流；完整候选的资源结果仍以上表真实 worker 回测为准。

记录到的首层交换子相对残差范围为 **1.1860–1.3491**，原程序的结构拒绝门槛为 0.7。它在这些 probe 上无法沿原来的固定配对学习完整基。

使用真实过去解、按当前 H 度量投影到最近 16 个解的诊断，各 public 序列平均 loss 范围 **0.0969–0.2786**。不使用当前或未来真解建立历史空间。该投影只检验历史解子空间，不是所有回收算法的下界；前期窗口不足 16，不能称为全程满窗口结果。

## 正确性与限制

独立行向量实现审计全部 **2250 个系统**，验证参考残差、F 能量恒等式、参考解重建、零/精确输出的 loss，以及因子严格谱界；并在每例 3 个时刻用块探针与生产 HVP 交叉核验。最坏参考相对残差 **7.52e-13**，独立后端差异 **0**。三种配置另用 64 维显式稠密 Q/F/H 与直接分解核验。

已知程序在有限样本上不饱和，不证明所有结构学习方法失效、没有闭式计算路径或达到 lower bound。通用预条件、子空间回收及合法结构识别继续允许。当前没有声称参照是 SOTA，也没有换成针对 private 的新参照。

目标机镜像、进程隔离、重新标定、重复运行稳定性和参照余量政策尚需维护者验收；本地无 Docker，不能声称通过 Linux 正式槽测试。不要在这些门槛完成前切换 task.json 为 formal。

模型只接收六文件小包；public 只汇总反馈，不给逐例/构造标签；private 仅冻结后的最终提交使用。完整包、仓库、指南、分析和生成器不进模型工作区。参见 [使用指南](../versions/v4/USAGE_GUIDE.zh.md)。
