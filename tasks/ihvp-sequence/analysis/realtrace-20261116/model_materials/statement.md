# 时序正定线性系统求解（诊断实验）

一条序列包含50个16384维系统：

$$H_t x_t^\star=b_t,\quad b_t\ne0,\quad 0<\mu I\preceq H_t\preceq LI.$$

每步只提供当前右端项、时刻编号、阶段标识、全序列谱界和HVP接口。提交当前解后才提供下一步；坐标编号保持不变。每条序列从空状态的新进程开始，可以在序列内保存历史向量、搜索方向或预条件信息，自行分配50步的计算时间。相关性不构成固定低维控制量或低秩结构的保证。

程序使用单进程、单CPU线程，完整序列墙钟不超过30秒，求解进程峰值RSS不超过256MiB。计时包含启动、导入、通信、所有HVP、预处理、历史刷新、求解与输出。评测端数据装载、参考解构造和事后验分不计时、不计入求解进程内存。禁止GPU、网络、额外进程/线程、读取评测端文件或跨序列保存实例状态。

每步返回有限向量，原始loss为归一化平方能量误差：

$$\ell_t=\frac{(\widehat x_t-x_t^\star)^\mathsf T H_t(\widehat x_t-x_t^\star)}{(x_t^\star)^\mathsf T H_t x_t^\star},\quad E=\frac1N\sum_{i=1}^N\frac1{50}\sum_{t=1}^{50}\ell_{i,t}.$$

零输出loss为1。无需达到指定残差阈值；精度不决定输出合法性。本诊断阶段只比较原始loss与资源合规性，尚无有效0/50分锚点。任一序列超限、缺失输出、异常退出或输出非法，整份提交不进入有效loss排名。
