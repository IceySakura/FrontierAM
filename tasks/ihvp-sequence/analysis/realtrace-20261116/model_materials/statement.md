# 序列正定线性系统求解

一条序列包含50个16384维系统：

$$H_t x_t^\star=b_t,\quad b_t\ne0,\quad 0<\mu I\preceq H_t\preceq LI.$$

每步只提供当前右端项、时刻编号、阶段标识、全序列谱界和HVP接口。提交当前解后才提供下一步；坐标编号保持不变。每条序列由一个初始状态为空的新进程顺序处理，进程状态可在本序列的调用之间保留。50步共享同一时间预算，各步使用的计算时间由程序自行决定。

程序使用单进程、单CPU线程，完整序列墙钟不超过30秒，求解进程峰值RSS不超过256MiB。计时包含启动、导入、通信、所有HVP、预处理、求解与输出。评测端数据装载、参考解构造和事后验分不计时、不计入求解进程内存。禁止GPU、网络、额外进程/线程、读取评测端文件或跨序列保存实例状态。

每步返回有限向量，原始loss为归一化平方能量误差：

$$\ell_t=\frac{(\widehat x_t-x_t^\star)^\mathsf T H_t(\widehat x_t-x_t^\star)}{(x_t^\star)^\mathsf T H_t x_t^\star},\quad E=\frac1N\sum_{i=1}^N\frac1{50}\sum_{t=1}^{50}\ell_{i,t}.$$

零输出loss为1。无需达到指定残差阈值；精度不决定输出合法性。计分固定Warm CG为0分参考、Cold CG为50分参考。评测端在同一机器、同一池重跑两者，得到E_0（Warm CG）、E_{50}（Cold CG），必须满足E_0>E_{50}>0。先对整池等权平均loss后换算一次分数，不逐例换算后平均。

$$S(E)=\begin{cases}0,&E\ge E_0,\\50\,(E_0-E)/(E_0-E_{50}),&E_{50}\le E<E_0,\\100-50E/E_{50},&0\le E<E_{50}.\end{cases}$$

public和private的数值分别标定；缺少完整标定时记未测。任一序列超限、缺失输出、异常退出或输出非法，整份提交记0分，不进入有效loss排名。
