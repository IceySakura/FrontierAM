## v2 实验（隐藏生成代码）阶段观察（2026-11-11 16:55，私有集评分待尝试结束后进行）

- 工作区只有题面、smoke、协议代码与 `run_sample.py`；完整样例的 HVP 由宿主服务提供。两次尝试的代码里都没有 DCT、余弦变换或符号恢复。
- 单轮：Galerkin 回收 CG——历史解张成子空间上的投影热启动，加 C 写的 CG 内核。
- 迭代（18 次测试）：最近 16 个解做 QR，在子空间上精确投影得到初始解，再跑 CG，按剩余步数分配时间（阶段切换后多给），用 Gauss–Radau 上界停止。public 分数 83.7 → 99.2 → 稳定在 99.6，最近 99.8；汇总误差约为 L-BFGS-PCG 的 1/270。
- 解读：右端项与矩阵由 6 维控制量与秩 12 修正驱动，解序列几乎落在低维子空间里，投影到最近十几个解就能拿到大部分精度；参照 L-BFGS-PCG 不利用这一点。因此隐藏代码挡住了“识别生成结构”，但挡不住“通用方法也接近满分”：参照偏弱、数据结构过于简单、50 分以上的线性映射饱和，这三点需要出题人处理（例如更强的回收类参照、提高控制量维度和突变强度）。
- 反馈观察：在两份参照都解到机器精度的类别上，类别锚点倒挂（弱参照甚至比强参照准），类别分数失去意义（比值 1e-5 仍记 0 分）。总分与比值不受影响。

## v2 结果（2026-11-11 19:15）

- 单轮私有集：\(E = 3.0\times10^{-4}\)（L-BFGS-PCG \(W = 0.0543\)，CG \(U = 0.1213\)），99.7 分；最长序列 28.4 秒，峰值 RSS 77 MiB。迭代私有集 \(E = 1.5\times10^{-4}\)，99.9 分（public 最高 99.8）。
- 两次尝试的最终代码都没有 DCT、余弦变换或符号恢复：隐藏生成代码挡住了“识别结构”，但通用的历史子空间投影加 CG 仍接近满分。
- 解序列为什么近似低秩：对角权重 \(a_t = 1 + \text{amp}\cdot\tanh(c_t F^\top)\)、秩 12 权重 \(r_t\)、强迫项 \(f_t = f_0 + 0.45\,G c_t\) 都由 6 维控制量 \(c_t\) 驱动，控制路径是 50 步内 0.75–2.5 个周期的低频正弦（只有阶段突变类会重启）。Galerkin 投影给出子空间内能量范数下的最优近似，精度只取决于解离历史子空间多远，与条件数无关，于是条件数 1e7 的难点被绕开。
- 建议：生成器提高控制维度与路径频率（或加随机游走）、强迫项加满秩分量、增加突变次数和强度；50 分参照换成带子空间回收的人类方法；50 分以上改对数刻度。保留 v2 的“样例走宿主 HVP 服务”。
