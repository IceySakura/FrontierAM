## 题目背景

隐式微分、连续参数估计及随时间变化的二次模型会产生一串相关的线性系统。程序每个时刻只看到当前右端项和矩阵向量积接口，可以复用历史解、搜索方向或预条件信息，并自行分配整条序列的计算时间。

本题用共享潜变量驱动矩阵和右端项，包含低有效秩、宽谱、聚簇谱、满秩漂移与阶段突变。快速隐式正交变换使高维 HVP 保持便宜；不向求解器交付完整矩阵、私有生成参数或未来输入。轨迹是固定的外生合成轨迹，未评估求解误差反过来改变外层优化的闭环效果。

## 评测依据

- **系统**：每例 \(d=16384\)、\(T=50\)，\(H_t x_t^\star=b_t\)，\(\mu I\preceq H_t\preceq LI\)。输出当前解后才提供下一步。
- **数据**：public 反馈池与 private 正式集各 15 条，为五类时序场景 × 三档谱尺度；samples 从 public 中选两条完整规模样例，另有 4 维 3 步 smoke。GitHub 不存私有教师数据、参考答案或私有种子。
- **资源**：单 CPU 线程；整批平均每序列 ≤30 秒，同时每条 ≤30 秒；所有序列中的最大求解进程峰值 RSS ≤256 MiB。启动、导入、协议、HVP、预处理、计算和输出计入时间。
- **原始指标**：\(\ell_t=\|\widehat x_t-x_t^\star\|_{H_t}^2/\|x_t^\star\|_{H_t}^2\)。先对 50 步平均，再对序列等权平均得 \(E\)；零输出 loss=1。残差阈值仅作诊断，不作合法性门槛。
- **映射**：本机重测 CG 得 \(E_0\)、L-BFGS-PCG 得 \(E_{50}\)。\(E\ge E_0\) 为 0；两锚点间为 \(50(E_0-E)/(E_0-E_{50})\)；\(E<E_{50}\) 为 \(100-50E/E_{50}\)。
- **失败**：提交导致的资源超限、缺失或非法输出使整份提交 0 分；平台、数据或本机校准缺失记“未测”，不能记 0 分。
