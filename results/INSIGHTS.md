# 结果解读：已有成绩说明了什么（2026-11-11，每轮评分后更新）

每道题根据已有成绩回答：参照是否偏弱、题目或数据是否有缺陷、评分映射是否合适、模型是否确实解决不了，以及模型超过参照时靠的是工程调参还是方法创新。以协议 v6.3 为主，参考旧版本成绩（按题目版本标注可比性）。各题 README 的“结果解读”一节是同一份内容。

## 类别与标注

| 类别 | 判断依据 |
| --- | --- |
| 参照偏弱 | 模型或已知人类方法大幅超过参照，超出部分来自现成方法或工程 |
| 题目或数据缺陷 | 存在不符合题意的捷径（泄露、可识别的生成结构）、数据太少，或样例与正式集分布不符 |
| 评分映射问题 | 饱和（多个解挤在高分段）、断崖（明显进步仍是 0 分），或刻度不适合指标量级 |
| 题面或接口问题 | 题面与实际评测不一致，或模型多次误解同一要求 |
| 模型未能解决 | 远低于参照，反馈中看不到接近的趋势 |
| 工程或调参超过参照 | 超出部分来自已知方法的组合、实现质量或针对指标的调参 |
| 方法创新（候选） | 找不到人类先例，且消融显示这一步贡献大；只作个例研究，不影响分数 |
| 设施影响 | 结果受评测故障影响（已重跑或待重跑） |

- **置信度**：实测（有直接测量）、推断（由测量和代码阅读推出）、待查（还缺关键证据）。
- **关注**：**需出题人处理**——题目、数据、参照或映射需要出题人修改（按 `results/BASELINE_POLICY.md`，包括任一格子 ≥ 80 分）；建议人工复核——判断依赖推断，或可能改变结论。

## 补充分析

**分数区间（配对 bootstrap，`scripts/analyze/v63-bootstrap.py`）**：按用例有放回重抽 5,000 次，每次在同一批用例上重算两条参照锚点和候选的原始指标，再换算分数。区间只反映“换一批用例”的抽样波动，不反映模型再跑一次的波动（每格只有一次尝试）。

| 题目 | 用例 | 单轮（95% 区间） | 迭代（95% 区间） | 迭代 − 单轮 |
| --- | --- | --- | --- | --- |
| species-tree-v3 | 96 | 49.3（39.8–51.2） | 52.6（51.3–53.9） | 1.9–11.9 |
| polarization-demosaicking-v2 | 32 | 53.5（51.8–54.9） | 52.9（51.4–54.4） | −1.1 – −0.1 |

**conic 映射敏感性**：官方映射在 \(p \le 0.9\,p_B\) 时记 0。换成从 0 开始的线性映射 \(50\,p/p_B\)，单轮 35.4、迭代 42.2；断崖放在 \(0.5\,p_B\) 时为 20.8 / 34.4。

**trajectory 题面核对**：题面加粗写明“交付的矩阵是 \(H\)”，并说明 \(H/M\) 才是均值的协方差；单轮把估计除以轨迹长度属于模型失误。

- 建议人工复核 · [galaxy-gravity](../tasks/galaxy-gravity/README.md) · 方法创新（候选）：sol 的核拆分（牛顿部分用调和展开，软化差项用笛卡尔展开）未找到完全相同的文献先例；在人类实现上做消融，这一步贡献最大（1.9× → 9.7×）。需要领域专家确认先例。
- 建议人工复核 · [ihvp-sequence](../tasks/ihvp-sequence/README.md) · 题面或接口问题：反馈的类别分数在两份参照都解到机器精度的类别上锚点倒挂（弱参照比强参照还准），比值 1e-5 仍记 0 分；总分和比值不受影响。可改为类别锚点倒挂时只显示比值。
