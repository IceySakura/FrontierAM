# 参照（baseline）原则（用户确定，2026-11-10）

适用于新题接入和更换参照。参照记 50 分，所以参照本身是否够强，决定了“超过参照”有没有意义。

1. **选参照：按本机实测强弱选，顺序如下。**
   - 有开源代码的人类 SOTA。
   - 有可执行程序的闭源 SOTA（如商业求解器），许可允许时直接运行原版。
   - 只有论文的 SOTA：由未接触任何模型提交的人或 agent 独立实现；在论文自己的基准上复现出论文报告的结果才算合格。
   - 能用多个就组成参照组，逐例取最好者。
   - “强”指在本题的规则下（单核、时限、精度要求、运行环境）实测最强，不是论文里最强。
2. **先调参、再冻结、后开放。** 参照只用公开数据、按事先声明的规则调参，冻结后才开始模型尝试。
3. **发布前确认计分不封顶。** 用一个已知优于参照的方法试算，确认它拿不到接近满分；跨数量级的指标用对数换算；参照耗时离时限至少留 25% 余量。
4. **参照被打败时，判断是调参还是算法创新。** 由被评模型以外的人或 agent 做消融：把模型解法的参数或 insight 放回人类参照实现。
   - 差距基本消失：属于调参，把 insight 并入人类参照，发布新一版参照（代码仍是人类实现，并注明 insight 的来源）。
   - 差距消失不了：属于算法创新，记为模型的成绩，参照不变。
   - insight 只用公开数据验证，不接触私有集。
5. **参照分版本，不追溯改分。** 每个成绩注明对应的参照版本；旧成绩保持不变；不同参照版本的成绩不混排。
