## x86_64 的验证边界

两题提供独立的 `linux/amd64` Docker 构建入口。构建及依赖加载检查记录在 [image_builds.json](image_builds.json)。本机只有 ARM64 CPU，x86 镜像的构建/启动检查使用模拟执行；这不能代替目标 Linux x86_64 的完整运行验证，也不能用于性能评分。

目标服务器必须依次运行 README 中的镜像构建、`prepare`、`smoke --task both` 和指数传播 `calibrate`。`prepare` 拒绝跨架构模拟评分；校准绑定 Docker host、镜像、数据与报告哈希。内核隔离能力以真实 smoke 为准，失败时应修复环境，不能删除隔离检查继续评分。

优化器保留更新包的完整 650 例和原裁判；当前 Nexus 入口仍为预先固定的 20 例探针，输出成功率，不虚构全量 0–10 分。指数传播的本机参考为冻结作者 KIOPS 实现（统一容差倍率 0.01），须在目标服务器通过全部 69 次验解才启用 0–100 分映射。
