# 先做三遍定向扫描

下面的问题**靠三遍定向扫描才看得出来，不要凭整体印象跳过**。每张关键截图都按这三遍看：

- **扫轮廓**：主体与背景的边界 —— 参差/破损的外形、缺面导致内部透出来、被一个看不见的
  平面平切掉的部分、悬在半空中断掉的部件。
- **扫接缝与接触点**：两个部件相接处，是互相穿透还是留着无法解释的缝隙？物体与地面/底座
  相接处，是**放在**上面、**沉进**里面、还是无支撑地**悬在**上方？有接触阴影吗？
- **扫表面**：色带、拉伸或重复的贴图、未受光的黑斑、闪烁的双层面（z-fighting）、形体消失
  掉的纯白过曝区域、细节消失掉的纯黑区域。

# 打分心态

- 以第一印象为重，但扫描发现的问题优先于第一印象。
- **不确定某个现象算不算问题 → 就算它是问题。** 分不清一个缝隙是穿模还是设计、一团光是
  过曝还是效果，就判给作品不利。漏掉一个真问题远比误报一次糟糕。
- **不确定需求有没有要求某样东西 → 就算它没有要求。** 只有需求正文点名的对象才算要求，
  标题或类目标签里出现的字样不算。
- **高分必须同时满足：渲染干净 + 建模到位 + 明显的场景搭建投入。三者缺一不封顶。**
- 5 分极其罕见，只给影棚级水准。
- 严查致命伤：canvas 黑屏、核心场景缺失、只有控制面板没有 3D 内容 → 直接压到 0-1 分。

# 各维度 0-5 分标准（每维必须给出加/减分理由）

每维基础从 2.5 起（中庸），按下列加减：

## rendering 渲染质量

加分：画面干净无瑕疵(+)、材质有质感、贴图分辨率与场景匹配(+)、后处理克制得当(+)。
减分：过曝/过暗导致主体难辨(--)、闪烁的双层面 z-fighting(--)、色带(-)、
贴图拉伸或明显重复(-)、未受光的黑斑(-)、shader 报错留下的破面(---)、
canvas 黑屏或核心场景缺失(---)。

## geometry 几何与空间关系

加分：结构完整、部件咬合准确(+)、朝向姿态比例合乎逻辑(+)、多物体堆叠层次清楚(+)。
减分：模型之间明显穿透或嵌入错误位置(--)、齿轮/关节/连接件穿模或脱离(--)、
空壳或缺背面（换个角度就透视或开口）(--)、几何体被地面平面或裁剪面切开(--)、
对象堆积到结构不可辨认(-)、标签/轨迹脱离对应对象(-)、UI 遮挡核心模型(-)。

## grounding 物理与接地关系

加分：接地关系明确、有接触阴影(+)、光影方向自洽(+)、布料/绳索垂坠自然(+)。
减分：悬浮 —— 物体没接地也没有悬浮的理由（旗子飘在旗杆旁而不是连着、椅子腿不着地）(--)、
物体插进地面而不是放在上面(--)、阴影与光源方向矛盾(-)、接地物体完全没有接触阴影(-)、
该垂坠的僵直或不自然拉伸、旗子平得像块板(-)、比例暗示不可能的质量（巨石平衡在细枝上）(-)。

## fidelity 建模保真度

看的是**与需求点名对象的差距**。

加分：几何体一眼读得出是需求要的那个物体(+)、关键部件齐全(+)、
细节层次达到需求暗示的水准(++)。
减分：读起来不是那个物体，是一团模糊的东西(--)、
用替代基本体糊弄（要求建模却给了个裸球、裸立方体）(---)、
比例严重错误（「汽车」的轮子有车身一半高）(--)、
缺关键部件（齿轮组没有啮合的齿、植物没有叶子）(--)、
细节层次远低于需求暗示的水准（要求影棚级 PBR，给了无贴图的平面基本体）(--)。

## composition 构图与镜头

加分：主体在画面里的位置和占比得当(+)、景深/视角凸显主体(+)、
背景与主体分离清楚(+)、光照塑造出体积感(++)。
减分：主体被裁切或挤在角落(-)、视角平淡看不出立体(-)、
背景与主体糊成一片(-)、构图无焦点(-)、HUD 与场景争夺注意力(-)。
