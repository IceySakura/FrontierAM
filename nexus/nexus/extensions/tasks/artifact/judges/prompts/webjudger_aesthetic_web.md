# 打分心态

- 以第一印象为重,相信直觉。
- 优秀的简洁≈高级(克制留白、考究间距);但简陋粗糙≠简洁——空荡无内容是减分,不是留白。
- **高分必须同时满足:视觉精致 + 设计复杂度 + 明显的工作量投入。三者缺一不封顶。**
- **平庸的模板感、安全无记忆点的配色 = 2-3 分,不是 4 分。** 5 分极其罕见,只给行业标杆。
- 严查致命伤:内容大面积空白、布局崩塌、元素重叠、渲染破碎、3D 场景空洞/模型残缺 → 直接压到 0-1 分。

# 各维度 0-5 分标准(每维必须给出加/减分理由)

每维基础从 2.5 起(中庸),按下列加减:

## composition 构图布局

加分:网格精准、模块清晰有序(+)、布局有创新又不失易用(++)、空间利用高效、视觉动线流畅(+)。
减分:布局混乱/随意无章法(--)、对齐乱、重要内容被压缩、大面积无意义空白(-)、陈旧无新意(-)。

## color 配色

加分:配色协调有记忆点、对比得当、强调色用得准、渐变/明暗过渡考究(+)。
减分:配色安全平庸无记忆点(-)、对比不足难读、语义不一致、刺眼或脏(--)、有明显ai配色模版，蓝紫色渐变配色(--)。

## typography 字体排版

加分:层级清晰、主次分明一眼抓重点、字体考究可读性佳、字号/行距节奏好(+)。
减分:排版杂乱动线混乱(--)、主次不分、信息过密拥挤(-)、重要信息被淹没(-)。

## coherence 一致性与风格契合

加分:视觉语言统一、完美匹配产品定位与当代审美(+)、设计元素协调(+)。
减分:风格与产品定位不符(--)、元素矛盾混乱、老气不合时代(-)。

## polish 精致度与完成度

加分:像素级打磨、边距统一对齐精准、细节质感突出、能看出资深设计师的大量投入(++)。
减分:细节粗糙边距不一(-)、元素模糊失真(-)、半成品/粗制滥造感(--)、致命伤(内容空白/崩塌/3D空洞)(---)。

# 输出（严格 JSON）

只返回一个 JSON 对象，不要输出 Markdown 代码围栏、XML、前后说明或额外字段。

每个维度的对象中，**先写 `reason`，再写 `score`**。必须先摆出图中观察到的加分项和减分项，
再由这些理由推出分数，不允许先定分再补理由。

`reason` 要求:
- 引用**具体视觉事实**(哪个区域、什么元素、什么颜色/间距/字号问题),不要写"整体不错"这类空话。
- 明确点出命中了上面哪些加分项 / 减分项,以及各自的力度(+ / ++ / - / -- / ---)。
- 从 2.5 基准出发说清怎么加减到最终分,例如"基准 2.5,网格精准(+0.5),但大面积空白(-0.5),
  配色平庸无记忆点(-0.5) → 2.0"。
- **五个维度都必须有非空 `reason`，一个都不能省、不能写"同上"。**

`score` 必须是 JSON 数字，范围为 0-5，不要写成字符串，不要附加“分”等文字。
