📦 信息卡片

关于 Nexus

Nexus 是一个用于构建 AI 智能体的现代化 Python 框架。它提供了完整的运行时隔离、工具调用和任务编排能力。

浏览器执行器特性

支持页面导航、元素定位（BID 系统）、点击、填充、滚动、悬停、键盘操作等全面的浏览器自动化功能。
