FrontierAM 任务看板

前沿数值算法任务上的模型评测：题目、评测依据、人类基线与各模型的做法和成绩

FrontierAM 收集的是有明确对错和可复现评分的数值算法题：每道题有公开的题面和开发数据，有隐藏的正式测试集，有在本机重新实测的人类参照实现（baseline）。每个模型在每道题上只有一次开发机会：断网的独立开发环境、固定的墙钟预算（默认 2 小时，含模型请求和工具时间），结束时冻结源码，再在隔离的评测核上用正式评测器打分。

分数约定：所有题目统一换算到 0–100 分。本机重测的参照实现记 50 分，题目可达到的最好结果记 100 分，无效提交记 0 分；评测平台故障记为“未测”，不记 0 分。每个分数都同时给出原始指标和换算方式。

题目

凸锥优化求解器

数值优化

从零实现一个通用凸锥优化求解器，覆盖线性、二次、二阶锥、半正定和指数锥，650 个隐藏实例，逐例时限 1–300 秒（出题方 2026-11-05 修正版题包）。

稀疏系统的指数传播（对标人类 SOTA）

数值线性代数

对大型稀疏对称半正定矩阵计算 \(e^{-tL}b_0 + t\varphi_1(-tL)b_1\)，在给定精度下越快越好；参照是 7 个已发表方法逐例取最快者。

星系快照中的引力加速度（131,072 个粒子）

科学计算 / N 体

粒子数加倍到 131,072、每次调用仍是 5 CPU 秒，使精确的直接求和无法在预算内完成，比较近似算法的精度。

偏振马赛克图像重建

计算成像

从一张 1024×1024 的偏振马赛克中重建 0°/45°/90°/135° 四幅完整图像，每景 1 秒，RMSE 越小越好。

从一条 MCMC 轨迹估计长期协方差

统计计算

只给一条马尔可夫链轨迹，估计样本均值的长期协方差矩阵（MCMC 标准误的核心），30 种设置平均的白化误差越小越好。

从短基因的估计树推断物种树（250 个物种，FrontierAM 重建版）

计算生物 / 系统发育

50 棵互相矛盾的估计基因树、250 个物种、120 秒；数据由我们按标准模拟流程重建并校准到原题的统计量，200 个正式用例。
