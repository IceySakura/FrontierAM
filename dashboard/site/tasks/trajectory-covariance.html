总榜评测协议

从一条 MCMC 轨迹估计长期协方差

统计计算 · 只给一条马尔可夫链轨迹，估计样本均值的长期协方差矩阵（MCMC 标准误的核心），30 种设置平均的白化误差越小越好。

题目背景

MCMC 的输出是相关的样本，不能用独立样本的公式算均值的标准误；需要估计“长期协方差” \(\Sigma = \lim n\,\mathrm{Cov}(\bar X_n)\)，它决定了有效样本量和收敛诊断。经典方法有批均值（BM/OBM）、谱方差估计和基于 VAR 模型的拟合；难点在于不同采样器（随机游走 Metropolis、NUTS、Pólya–Gamma Gibbs、有限状态链）的自相关结构差别很大，而且轨迹长度从几千到几万步不等。

公开题面原文（给模型的版本）

题目名称

从一条采样轨迹估计长期协方差

问题描述

研究者运行一次马尔可夫链蒙特卡洛采样，得到按时间排列的向量 $x_1,\ldots,x_M$，用它们的平均值估计多个量。若在同样条件下独立重跑，某些分量的平均值可能波动较大，两个分量的平均值也可能一起偏高。你的程序每次只得到其中一次运行的轨迹。

算法目标

给定这条轨迹，返回 $d\times d$ 的长期协方差估计 $H$。目标量为 $\Sigma=\lim_{n\to\infty}n\,\mathrm{Cov}(\bar X_n)$，其中 $\bar X_n$ 是一次长度为 $n$ 的运行的平均向量。对足够长的轨迹，$H/M$ 估计均值向量的协方差，$\sqrt{H_{jj}/M}$ 估计第 $j$ 个均值的标准误。交付的矩阵是 $H$。

算法约束

同一程序处理六种情形。模拟轨迹有线性动态的四维观测和有限状态链的五维观测。真实数据部分对一个贝叶斯回归模型使用三种采样机制，每步给出六维观测。输入坐标可能经过固定于本条轨迹的可逆线性变换和平移。程序可反复读取本条轨迹、自选算法、拟合参数或使用现成数值库。估计必须来自本例输入与通用算法，禁止查表返回特定模型的参考答案、识别测试文件后套用答案、追加采样或跨调用传递数据。

离线 Linux ARM64，每次调用独享一个逻辑 CPU，单线程，2 GiB 内存，无交换空间，墙钟上限 30 秒。时间包括程序启动、读取输入、计算和写完输出。需要随机性时用固定环境变量 SEED=1。可用 Python 3、NumPy、SciPy、R 或 C/C++，其他依赖随源码提供并能离线构建。

交付要求

在 /workspace/submission/ 提交源码、可执行的 run.sh 和说明依赖、来源及运行方法的 README.md。需要构建时提供无参数的 build.sh，在评测前用相同 CPU 和内存配额构建一次，限 300 秒。每例启动全新进程，入口为

./run.sh /absolute/input/input.npy /absolute/output/pred.npy

输入和输出都是单个 NumPy .npy 数组，C 顺序、小端 float64、无 pickle。输入形状为 $(M,d)$，行序为采样时间，列序为本例的分量顺序。输入中没有情形标签或其他轨迹。请按相同列序写出形状为 $(d,d)$ 的有限、对称、半正定矩阵，正常退出。零特征值合法。

评测指标

评测方持有正定的参考矩阵 $S$。模拟情形的 $S$ 可从生成机制求出，真实数据情形的 $S$ 用独立长链估计。每次有效输出的误差为

$$e=\left\|S^{-1/2}(H-S)S^{-1/2}\right\|_F.$$

越小越好。数值验收取 $s=\max(1,\|H\|_F)$，要求 $\|H-H^\mathsf T\|_F\le10^{-10}s$，且对称化后最小特征值至少为 $-10^{-10}s$。评分前对允许的微小非对称取平均，并把容差内的负特征值置零。超时、超内存、非零退出、缺失或非法输出的该例按提交零矩阵计误差 $\sqrt d$，保留在平均数内。整份构建失败得 0 分。

模拟三种情形各取 5,000、10,000、20,000、40,000、80,000 步，真实数据三种情形各取 2,500、5,000、10,000、20,000、40,000 步。每档先对 1,000 条轨迹分别算误差后取算术平均，再对全部 30 档等权平均，得总误差 $L$。模拟与真实数据各占 50%。每条母链的五个前缀分开调用。耗时只作限额与诊断。

基础参照和强参照在相同正式输入上的总误差分别为 $a>b>0$。当 $L\ge a$ 得 0 分；当 $b\le L<a$ 得 $5(a-L)/(a-b)$ 分；当 $0\le L<b$ 得 $10-5L/b$ 分。对每份提交只换算一次，满分 10 分。

评测依据

  • 输入：一条 \(M \times d\) 的轨迹（\(d\) = 4、5 或 6），坐标可能经过本条轨迹固定的可逆线性变换和平移。
  • 正式集：6 种情形（3 种模拟、3 种真实数据采样器）× 5 种长度 = 30 档，每档 1,000 条母链；全量 3 万个输入。本机默认评测固定的 10% 分层子集（每档前 100 条母链，共 3,000 个输入），出题方的封存 agent 在同一子集上复评一致。
  • 资源：每例单核、2 GiB、墙钟 30 秒（含启动）。
  • 原始指标：每例白化误差 \(e = \|S^{-1/2}(H-S)S^{-1/2}\|_F\)；每档平均后 30 档等权平均得 \(L\)。失败的例按零矩阵记误差。
  • 换算：设 OBM 的 \(L\) 为 \(a\)、拟合 VAR(1) 为 \(b\)。\(L \ge a\) 记 0 分；\(b \le L < a\) 记 \(50(a-L)/(a-b)\)；\(L < b\) 记 \(100-50L/b\)。

模型自己写的说明（提交中的 README.md）

Long-run covariance from one trajectory

./run.sh INPUT.npy OUTPUT.npy reads one (M, d) float64 trajectory and writes the (d, d) estimate H of Sigma = lim n Cov(mean_n): symmetric, PSD, <f8, C order.

Dependencies

  • Python 3 with NumPy. Tested with Python 3.11 and NumPy 1.26.
  • No other packages and no build step, so there is no build.sh.
  • Runs single-threaded: run.sh sets the BLAS thread variables to 1.
  • Randomness comes only from numpy.random.default_rng(SEED). SEED defaults to 1, so results are deterministic.
  • All code is original and lives in lrcov.py.

Method

Every step is affine-equivariant (x -> A x + b gives H -> A H A^T). The program never uses a model label: it chooses between two general model classes using only the data.

0. Whitening. Centre the trajectory and whiten it with the symmetric inverse square root of its sample covariance. This keeps the numerics well conditioned whatever coordinates the input arrives in.

A. Finite-state branch. Taken only when all of the following hold:

  • the trajectory visits few distinct points: K <= 200 and M >= 20 K;
  • every point is re-entered many times. This rules out continuous chains whose repeated rows come from Metropolis rejections;
  • a parametric-bootstrap G test does not reject a first-order Markov chain against a second-order one. The test uses 20 chains simulated from the fitted transition matrix and rejects at z > 4. Lumped or hidden-state chains are rejected here.

When it is taken:

  1. Put a Dirichlet posterior on the rows of the transition matrix, restricted to the observed transition support.
  2. For each draw P, compute the exact long-run covariance: F_c^T (D Z + Z^T D - D) F_c, where - Z = (I - P + 1 pi^T)^{-1} is the fundamental matrix, - D = diag(pi), - F_c holds the centred state values.
  3. Combine the draws with the Bayes step below.

B. VAR branch (everything else):

  1. Fit a VAR(p) by least squares. The order p is chosen by AIC with p <= min(40, M/(10 d)).
  2. Draw from the Jeffreys-prior posterior: Sigma_u ~ inverse Wishart, then B | Sigma_u ~ matrix normal around the OLS fit.
  3. When p = 1, first move the OLS centre by half of the Pope (1990) first-order bias correction (persistent chains are otherwise under-estimated). The correction is shrunk if needed to keep the fit stationary.
  4. Drop non-stationary draws (companion spectral radius at least 0.9995).
  5. Map each kept draw to (I - sum A_j)^{-1} Sigma_u (I - sum A_j)^{-T}.

Bayes step (both branches). Return the H that minimises the posterior mean of the evaluation loss || S^{-1/2} (H - S) S^{-1/2} ||_F over the draws S_s.

  • It is computed by iteratively reweighted least squares. Each step solves the d^2 x d^2 system sum_s w_s P_s H P_s = sum_s w_s P_s, where P_s = S_s^{-1} and w_s = 1 / loss_s.
  • The effect is to shrink the estimate exactly where it is uncertain. This matters most for slowly mixing short chains, where the plug-in estimate is heavy-tailed. In development tests it cut the mean error by up to 40% on such chains, and it never made things worse elsewhere.

Back-transform. Map H back to the input coordinates, then symmetrise and clip its eigenvalues at 0.

If anything fails, the program falls back to multivariate batch means with batch size floor(sqrt(M)). If even that fails, it writes the zero matrix.

The code also keeps some switches that are turned off because they did not help in development: a multi-resolution variant (VAR on m-block means with a Lepski choice of m) and alternative order rules (P_RULE).

Background:

  • VAR spectral estimation of long-run covariances: den Haan and Levin (1997), "VARHAC".
  • Bias of OLS VAR(1) estimates: Nicholls and Pope (1988) and Pope (1990).
  • Normal–inverse-Wishart / Jeffreys posterior for VARs: standard Bayesian VAR results.
  • Long-run covariance of a finite Markov chain via the fundamental matrix: Kemeny and Snell.
  • Testing Markov order with the G statistic: Anderson and Goodman (1957); here it is calibrated by parametric bootstrap.
  • Bayes estimation under the loss tr((S^{-1}H - I)^2): Haff (1980) and Olkin and Selliah (1977).

Running

./run.sh /abs/input.npy /abs/pred.npy
python3 check.py reference.npy /abs/pred.npy   # optional self-check with the dev pack

Run time is usually 0.3–3 s for M <= 80000 and d <= 6. Peak memory is a few hundred MB.
