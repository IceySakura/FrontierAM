# 题目目录

每道题一个目录，内容结构相同：

- `README.md`：怎么读这道题，题目背景、数据与代码位置、评测依据、baseline、模型成绩与解法；
- `statement.md`：给模型的题面原文；
- `public/`：公开开发材料的文本文件；
- `reference/`：参照实现源码（较小且不在仓库其他位置时）；
- `solutions/<模型>-<设置>/`：模型冻结提交的源码。
