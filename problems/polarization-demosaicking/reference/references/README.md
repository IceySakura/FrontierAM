# Polarization demosaicking references

The active `bilinear` and `reflect` source directories implement the published submission interface. The current `bilinear` implementation depends only on NumPy and fills the four output grids directly. The `reflect` implementation selects phase-preserving mirror extension from the unchanged vendored sources. The historical `bilinear-edge` implementation retains the vendored historical full-frame and LEIC sources. `source-manifest.json` identifies those vendored files and their historical upstream checksums. `verify.py` verifies those file hashes and compares both active outputs to the historical implementation in isolated processes.

The original `verification.json` documents the initial adapters. The earlier 1-second batch archives the exact old pure-bilinear adapter and all vendored files. The streamlined reference was checked against that archive on 201 synthetic inputs with bitwise equality, then through the ordinary 1-second worker on twelve full-size synthetic cases. The evidence includes the two source hashes, the raw output hashes, per-worker resource limits and timings.
