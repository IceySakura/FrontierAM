# 离线开发与运行环境

当前本地修订使用Python3.12.16、NumPy2.5.4、SciPy1.18.1。允许调用全部预装接口，包括高层数值函数；允许阅读这些库在镜像内的文档和源码。没有特定作者算法包或论文资料随题提供。Python标准库可用，不允许联网安装依赖或调用远端服务。

提交语言原则上开放，但最终发布必须提供明确、离线可用的编译器和依赖白名单。当前开发包可直接核对Python接口；Linux镜像摘要、其他语言工具链及正式硬件尚未冻结，所以当前不产生正式跨语言性能成绩。不得把“原则上允许语言”理解成最终镜像已经安装任意编译器。

正式开发和执行应分别使用干净的受限环境。开发2小时墙钟，1CPU、4GiB；公开数据测试不限次数但都消耗这份预算。最终执行仍遵守题面会话预算、无网络/GPU、无宿主挂载和私有裁判访问。普通构建不能读取任何最终测试输入。

开发工具只能反映其实际运行平台。工具自己不会把macOS变成Linux硬隔离环境；正式环境必须由外部控制器落实资源与可见性。参考与提交共享同一冻结可用软件环境，正式分数只在该环境中标定。
