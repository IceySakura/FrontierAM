# Exponential Propagation

This submission implements the FAMEXP2 binary streaming protocol in C++17
for real symmetric positive semidefinite CSR matrices. It computes
`exp(-t L) b0 + t phi1(-t L) b1`, including singular operators.

The executable uses only the C++ standard library. Building requires the
installed GCC toolchain on Linux amd64. No downloads, network access, Python
packages, agent tools, external data, or cross-session caches are required.

Build with `bash build.sh`, then run `./run.sh`. The launcher automatically
builds if the executable is absent. `build.sh` is the offline build entry
point for the evaluator. All paths are relative to this directory.

## Numerical Method

The general solver applies both functions in a single Chebyshev expansion.
Scaled modified Bessel coefficients are generated by a backward ratio
recurrence in extended precision. The phi1 coefficients follow from a
backward integrated coefficient recurrence. A combined Reinsch/Clenshaw
recurrence uses one sparse matrix-vector product per polynomial degree
for the sum of the two functions.

The spectral upper bound uses absolute row sums followed, where useful,
by positive-vector Collatz bounds for the absolute matrix. Euclidean-norm
coefficient-tail bounds are checked against the requested infinity-norm
tolerance, with a safety margin. For matrices with nonpositive off-diagonal
entries, row-difference products reduce cancellation near the nullspace.

Small scaled norms use an adaptive Taylor series. Localized inputs may
also finish before global preparation: for PSD matrices, the phi1 Taylor
remainder is bounded by the Euclidean norm of its first omitted term.
Disconnected scalar and 2x2 blocks have direct spectral formulas.
PSD contractivity also permits zero output when its full norm bound is
below half the absolute tolerance. Metzler generators use an additional
infinity-norm semigroup bound for this check.

Original matrix entries and extended-precision coefficients are retained.
Cancellation-heavy outputs are recomputed in extended precision, using the
original entries rather than rounded normalized coefficients. This protects
small absolute outputs as well as relative accuracy.

Generic buffers are allocated before `READY`; no input is read before it.
All matrix-dependent work occurs after `READY`, and each complete result is
flushed before reading the next request. The process exits after the last
result. It uses the inherited CPU affinity and creates no worker threads.

## Public Checks

Run the standalone standard-library protocol checks with:

```sh
python3 selftest.py
```

Development validation included:

- All 56 reduced-size public smoke sessions, three repeats each.
- All 40 full-size public one-shot sessions, three repeats each.
- All 72 formal public evaluator sessions, including sequential reuse.
- 60 additional sessions with 960 outputs checked against independent
  75-digit eigendecomposition references, including constructed cancellations,
  singular signed operators, PSD Gram matrices, and stiff 2x2 blocks.
- A maximum-size signed stress operator: 120,000 rows, 840,000 nonzeros,
  p10 accuracy, and scaled infinity norm 100,000. All 16 requests, including
  extended-precision recomputation, finished in approximately 102 seconds
  locally, below the 240-second limit, with reported peak RSS about 147 MiB.

Public timing is feedback only; no public matrices or reference outputs are
included in or consulted by this submission.
