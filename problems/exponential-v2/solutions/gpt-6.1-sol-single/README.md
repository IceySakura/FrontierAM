# Sparse Exponential Propagation

This submission implements the FAMEXP2 binary streaming protocol in C++17.
Build offline with `bash build.sh`, then run `./run.sh`. The build requires the
installed GNU C++ compiler and the standard C++ and C runtime libraries only.
The executable uses the inherited CPU affinity and starts no worker threads.

The constant source is folded into the initial state as `b0 + t*b1`, since a
constant source can be propagated from the beginning of the interval. The
general solver therefore expands `exp(-t*L)*(b0 + t*b1)` in Chebyshev polynomials
on a certified spectral interval for the received symmetric PSD matrix.
Both terms are evaluated together using a Reinsch-modified Clenshaw recurrence,
requiring one sparse matrix-vector product per polynomial degree.
Scaled modified Bessel coefficients are generated by a backward ratio
recurrence; integrated coefficients follow from positive coefficient sums.
Euclidean coefficient-tail bounds determine the truncation degree. A posteriori
output scaling can trigger a tighter evaluation. Stiff high-accuracy cases use
extended-precision arithmetic. Coefficients and matrix preparation are retained
only within the current session.

Zero times and zero matrices are handled directly. Matrices whose connected
components have at most two vertices use cached analytic 1x1 and 2x2 matrix
functions, including their singular eigenvalues.

Standard output contains only `READY\n` and the requested binary result vectors.
Set `FAMEXP_DEBUG=1` to send polynomial degrees to standard error.

The protocol and earlier numerical implementation were checked against all 56
reduced-size and 40 full-size public cases. The final shared-coefficient
simplification was rebuilt and checked for standalone startup.
